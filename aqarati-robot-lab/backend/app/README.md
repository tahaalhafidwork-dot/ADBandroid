# backend/app/

مكان واجهة التحكم ومحرك المعالجة في **Aqarati Robot AI Lab**.

هذه المرحلة **لا تحتوي** أي تنفيذ: البنية مثبّتة فقط، ووحدة التحكم ومحرك المعالجة
يُنفَّذان في milestone قادم هنا، مع احترام حدود الكتابة المعرّفة في
`backend/paths.py`.

القيود المطبّقة على أي كود يُضاف هنا لاحقاً:

1. قراءة البيانات من `data/processed/` أو `data/legacy/` فقط.
2. كل كتابة عبر `paths.write_text` / `paths.write_bytes`.
3. لا استدعاء لأي خدمة مدفوعة (Apify / Kilo API) أثناء التطوير المحلي.
