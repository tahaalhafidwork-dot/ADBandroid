# backend/

كود تطبيق **Aqarati Robot AI Lab**.

| الملف | المسؤولية |
|---|---|
| `paths.py` | جذر المشروع، حل المسارات النسبية، حارس حدود الكتابة |
| `config.py` | إعدادات مشتقة من جذر المشروع (لا مسارات مطلقة) |
| `legacy_import.py` | استيراد البيانات القديمة: نسخ أو مرجع، دون تعديل المصدر |
| `app/` | واجهة التحكم ومحرك المعالجة — **لاحقاً** |

## قواعد الكتابة

كل كتابة تمرّ عبر `paths.write_text` أو `paths.write_bytes`، وكل مسار يُشتق من
`paths.PROJECT_ROOT`. أي كتابة خارج جذر المشروع تُرفض بـ `paths.BoundaryError`.
