# frontend/

مكان واجهة التحكم في **Aqarati Robot AI Lab**.

هذه المرحلة لا تحتوي أي كواجهة: البنية مثبّتة فقط، ويبدأ بناء الواجهة في milestone قادم
دون التأثير على بقية المشروع.

القواعد المطبّقة اليوم:

- أي ملفات مصدر تُبنى هنا يجب أن تقرأ بياناتها من `backend/` عبر واجهة محلية
  (أو عبر `data/processed/`) ولا تصل إلى المشاريع القديمة مباشرة.
- لا تُحفظ أسرار أو مفاتيح API داخل هذا المجلد.
- المخرجات (صور، قواعد بيانات) تخزَّن خارج هذا المجلد.
