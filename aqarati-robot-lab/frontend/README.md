# Frontend

واجهة React + TypeScript + Vite عربية RTL. تستخدم Tailwind CSS وLucide وRecharts، وتتصل بالـAPI عبر proxy محلي في وضع التطوير.

```powershell
npm install
npm run dev -- --host 127.0.0.1
npm run build
```

لا تحتوي الواجهة على بيانات عقارية وهمية؛ حالات الفراغ و«غير متوفر» ناتجة عن استجابة API.
