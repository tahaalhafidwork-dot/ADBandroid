# بنية Aqarati Robot AI Lab

## الهدف

تقديم بنية مستقلة تماماً لمشروع **Aqarati Robot AI Lab**، بحيث يمكن بناء واجهة التحكم
ومحرك المعالجة لاحقاً دون خلطهما بالمشاريع والنتائج الموجودة مسبقاً في المستودع.

## الطبقات

| الطبقة | المجلد | المسؤولية | هذه المرحلة |
|---|---|---|---|
| النواة | `backend/paths.py` | جذر المشروع، حل المسارات، حارس حدود الكتابة | مكتملة |
| الإعدادات | `backend/config.py` | إعدادات مشتقة من جذر المشروع | مكتملة |
| الاستيراد | `backend/legacy_import.py` | نسخ أو مرجع للبيانات القديمة دون تعديل المصدر | مكتملة |
| التطبيق | `backend/app/` | واجهة التحكم ومحرك المعالجة | **لاحقاً** |
| الواجهة | `frontend/` | واجهة التحكم | **لاحقاً** |
| البيانات | `data/` | خام / معالجة / مستوردة / سجل | مكتملة |
| الاختبارات | `tests/` | حدود الكتابة وعدم تعديل الملفات القديمة | مكتملة |
| التوثيق | `docs/` | البنية والاستيراد والحدود | مكتملة |
| الأدوات | `scripts/` | استيراد، تحقق البنية، نظافة git | مكتملة |

## قواعد التصميم

1. **جذر واحد.** كل المسارات نسبية لجذر المشروع، ومُشتقّة من موقع الملف لا من متغيرات
   بيئة مطلقة.
2. **كتابة محصورة.** الكتابة داخل `aqarati-robot-lab/` فقط، وتُمرّ عبر `backend/paths.py`.
3. **قراءة فقط للخارج.** المشاريع القديمة مصادر قراءة فقط، مع بصمة SHA-256 قبل/بعد أي
   عملية استيراد.
4. **لا خدمات مدفوعة.** لا Apify ولا Kilo API؛ الاستيراد يعمل على ملفات JSON المحلية.
5. **لا بيانات حساسة في git.** الصور وقواعد البيانات والبيانات الخام والأسرار والسجلات
   مستبعدة عبر `.gitignore` الخاص بالمشروع.

## تدفق البيانات المستقبلي

```
مصدر قديم (قراءة فقط)
        │  legacy_import (copy | reference)
        ▼
data/legacy/  ──►  data/processed/  ──►  قاعدة بيانات محلية
        │                                      │
        └──────────────►  backend/app/  ◄──────┘
                              │
                              ▼
                        frontend/
```

الخط المتقطّع هو الحد الذي يحرسه `backend/paths.py`: لا شيء داخل التطبيق يستطيع الكتابة
خارج `aqarati-robot-lab/`.
